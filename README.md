# Stooks

Aplicación móvil para la gestión y control de inventarios.

## Descripción

Stooks es una aplicación desarrollada en Android Studio utilizando Kotlin y Jetpack Compose.

## Tecnologías

- Kotlin
- Jetpack Compose
- Android Studio
- MVVM

## Funcionalidades

- Gestión de productos
- Registro de inventario
- Control de entradas y salidas
- Consulta de productos
- Gestión de información del inventario
